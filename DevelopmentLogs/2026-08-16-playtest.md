## 4. 보스 체력바 구현

### 구현 내용

- 보스가 등장할 때만 화면 상단 중앙에 전용 체력바를 표시한다.
- `EnemySpawner.EnemySpawned`로 보스 등장을 감지한다.
- `Enemy.HealthChanged`로 현재 체력과 분홍색 게이지를 갱신한다.
- `Enemy.Died` 발생 시 체력바를 숨기고 이벤트 구독을 해제한다.
- 보스 이름과 `현재 체력/최대 체력`을 함께 표시한다.
- 기존 적 머리 위 체력바는 그대로 유지한다.

### 기능 확인 결과

- [x] 보스 등장과 동시에 `Overseer Boss 1000/1000`이 표시된다.
- [x] 보스가 공격받을 때 현재 체력 숫자가 감소한다.

## 5. 보스 UI 배치 조정

### 발견한 문제와 수정

1. 초기 체력바가 `Restart`, `Speed` 버튼과 겹쳤다.
   - 체력바 폭을 `320px → 270px`로 줄였다.
   - 게이지 폭을 `288px → 238px`로 줄였다.
   - 글자 크기를 `17 → 16`으로 조정했다.

2. 기존 `WARNING / OVERSEER BOSS INBOUND` 경고도 우측 버튼과 겹쳤다.
   - 경고 폭과 글자 크기를 줄이고 위치를 조정했다.

3. 체력바가 경고보다 나중에 생성되어 경고를 덮었다.
   - Canvas 생성 순서를 변경해 경고가 체력바보다 앞에 표시되도록 했다.

4. 체력바와 경고의 세로 영역이 겹쳤다.
   - 보스 체력바는 상단 중앙에 유지했다.
   - 경고는 화면 정중앙의 안전한 위치로 분리했다.

### 최종 확인

- [x] 보스 체력바의 이름과 수치를 읽을 수 있다.
- [x] 분홍색 게이지가 선명하게 표시된다.
- [x] 등장 경고가 체력바에 가려지지 않는다.
- [x] 등장 경고가 화면 가로 중앙에 표시된다.
- [x] 보스 체력바와 등장 경고가 충분히 분리되어 보인다.

등장 경고는 약 3초 동안 전투 영역 위에 표시된다. 적과 경로 일부를 일시적으로 덮지만 보스전 시작을 강조하는 연출로 받아들일 수 있고, 플레이를 지속적으로 방해하지 않으므로 현재 배치를 통과로 판단했다.
