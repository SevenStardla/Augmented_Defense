# 2026-08-20 플레이테스트 보고서

## 1. 테스트 목적

- 새 SF 전장 배경이 게임 오브젝트와 UI의 가독성을 해치지 않는지 확인한다.
- 적 경로와 전장 외곽의 타워 설치 제한을 확인한다.
- 디펜더의 화면 이탈 방지 기능을 확인한다.
- 새 비주얼을 포함한 1~5웨이브 통합 회귀 테스트를 진행한다.

## 2. 테스트 환경

- 테스트 날짜: 2026-08-20
- 작업 시작: 09:08 KST
- Unity 버전: Unity 6.4 (`6000.4.8f1`)
- 실행 환경: Unity Editor PlayMode
- 테스트 씬: `Assets/Scenes/Main.unity`
- 화면 조건: 일반 창 및 전체 화면
- 관련 커밋: `a564f8b` 및 후속 UI 수정
- Console 빨간 오류: 없음

## 3. 전장 배경 테스트

- 어두운 SF 회로형 배경이 화면 전체에 빈틈없이 표시됐다.
- 일반 창과 전체 화면에서 배경이 찌그러지거나 빈 공간이 생기지 않았다.
- 황금색 적 경로가 배경 위에서도 명확하게 보였다.
- 적, 디펜더, 타워와 코어가 배경에 묻히지 않았다.
- 좌측 상태 UI와 우측 버튼의 글자를 쉽게 읽을 수 있었다.
- 게임 실행과 기존 타워 배치 기능이 정상 작동했다.

## 4. 타워 설치 구역 테스트

- 적이 이동하는 황금색 경로 위에는 타워를 배치할 수 없었다.
- 경로 위를 클릭해도 실제 타워가 생성되지 않았다.
- 경로와 떨어진 정상 그리드에서는 초록색 미리보기와 함께 설치할 수 있었다.
- 전장 끝쪽 외곽에는 타워를 설치할 수 없었다.
- 기존 타워, 코어와 플레이어 디펜더 위에도 설치할 수 없었다.
- 디펜더는 경로를 자유롭게 가로지를 수 있었다.
- 적은 이전과 같은 황금색 경로로 정상 이동했다.
- 일반 창과 전체 화면에서 설치 판정이 동일했다.

## 5. 디펜더 화면 경계 테스트

- 화면의 네 가장자리까지 이동해도 디펜더가 화면 밖으로 나가지 않았다.
- 디펜더 몸체 전체가 화면 안에 남았다.
- 방향키를 계속 눌러도 화면 밖으로 사라지지 않았다.
- 일반 창과 전체 화면에서 동일하게 작동했다.
- 경계에 붙은 상태에서도 반대 방향으로 즉시 이동할 수 있었다.
- 경로 통과와 공격 기능은 이전처럼 정상 작동했다.

## 6. 1~5웨이브 통합 회귀 테스트

- 게임 시작 시 배경, 코어, 디펜더와 시작 타워가 정상 표시됐다.
- 정상 구역에는 보유 골드만큼 타워를 설치할 수 있었다.
- 일반 적, 러너와 탱커가 설정한 이미지와 크기로 등장했다.
- 모든 적이 경로 모서리에서 이동 방향대로 회전했다.
- 타워와 디펜더의 조준·공격 및 적 피격 효과가 정상 작동했다.
- 웨이브 종료 후 증강 패널과 `CHOOSE AN AUGMENT` 제목이 정상 표시됐다.
- 5웨이브에서 보스 이미지, 등장 경고와 체력바가 정상 표시됐다.
- 보스 처치 후 승리 화면이 표시됐다.
- 승리 상태에서 속도 표시가 `--`로 변경됐다.
- `Play Again` 후 골드, 코어 체력, 타워, 증강과 속도가 초기화됐다.
- Console에는 빨간 오류가 없었으며 재시작과 증강 선택 Debug 로그가 정상 출력됐다.

## 7. 통합 테스트에서 발견한 문제와 수정

### 좌측 상단 UI 사이 타워 배치

- 문제: 제목과 상태 글자 사이 빈 공간에서 타워 미리보기와 실제 배치가 가능했다.
- 수정: 좌측 상단 상태 UI 전체를 투명 입력 차단 영역으로 지정했다.
- 결과: 제목과 상태 글자 사이 및 증강 결과 표시 영역에서 미리보기가 사라지고 실제 타워도 생성되지 않았다.
- 정상 전장 영역인 좌측 UI 아래에서는 다시 설치할 수 있었다.

### 긴 디펜더 증강 결과와 우측 버튼 겹침

- 문제: `Reflex Accelerator`와 `Expanded Targeting` 선택 결과가 우측 버튼 영역에 걸렸다.
- 수정: 선택 결과를 왼쪽으로 이동하고 표시 폭과 글자 크기를 소폭 줄였다.
- 결과: 디펜더 공격속도와 사거리 증강 결과 모두 우측 버튼과 충분한 간격을 확보했다.
- `Start Wave`, `Restart`, `Speed` 버튼은 모두 정상 작동했다.
- 일반 창과 전체 화면에서 동일하게 적용됐다.
