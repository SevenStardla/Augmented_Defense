초기 수정에서는 버튼 자체의 클릭은 차단됐지만 버튼 사이 빈 공간이 월드 입력으로 처리될 가능성이 있었다. 우측 버튼 묶음 뒤에 입력 차단 패널을 추가한 뒤 다시 확인했다.

### 확인 결과

- [x] 우측 버튼 사이와 반투명 패널 영역에서는 배치 미리보기가 보이지 않는다.
- [x] 해당 영역을 클릭해도 타워가 생성되지 않는다.
- [x] `Start Wave` 버튼은 정상 작동한다.
- [x] `Restart` 버튼은 정상 작동한다.
- [x] `Speed` 버튼은 정상 작동한다.

### 판정

우측 UI 버튼과 버튼 사이 여백에서 월드 배치 입력이 모두 차단됐다. 입력 차단 패널이 버튼 동작을 방해하지 않는 것도 확인했다.
