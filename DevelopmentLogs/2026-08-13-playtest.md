# 2026-08-13 플레이테스트 보고서

## 1. 테스트 목적

- Unity `6000.4.8f1` 업데이트 후 기존 플레이 흐름과 재시작이 정상적으로 작동하는지 확인한다.
- 최신 WebGL 빌드에서 입력, 배속, 타워 배치, 증강, 보스전과 승리 처리를 확인한다.
- 일반 창과 전체 화면에서 발견된 게임 월드와 UI의 겹침을 수정하고 검증한다.

## 2. 테스트 환경

- 테스트 날짜: 2026-08-13
- Unity 버전: `6000.4.8f1`
- 에디터 테스트: Unity Editor PlayMode
- WebGL 테스트: 로컬 HTTP 서버 및 브라우저
- 테스트 씬: `Assets/Scenes/Main.unity`

## 3. Unity 버전 호환성 테스트

### 경고 확인

- `FindFirstObjectByType<T>()` 사용 위치 5곳에서 `CS0618` 경고가 발생했다.
- 기존 Input Manager가 사용 중단 예정이라는 경고가 발생했다.
- 두 경고 모두 현재 컴파일과 실행을 중단시키지는 않았다.
- 실제 컴파일 오류와 Console의 빨간 오류는 발생하지 않았다.

현재 검색 대상인 `GameManager`, `CoreHealth`, `Camera`, `EventSystem`은 각각 하나만 존재하므로 `FindFirstObjectByType` 경고가 실제 기능 문제를 일으키지 않았다. 실행 문제가 발생할 때 `FindAnyObjectByType`으로 변경하기로 하고 이번에는 기존 코드를 유지했다.

### 전체 플레이 결과

- [x] 기본 타워 1개와 추가 타워 1개가 정상 작동한다.
- [x] `Rapid Cycling` 2스택이 적용된다.
- [x] `Overcharged Turret` 2스택이 적용된다.

- [x] `Play Again`이 `Restart`와 동일하게 작동한다.
- [x] 재시작 후 배속, 골드, 코어 체력, 타워와 증강이 초기화된다.

### 판정

Unity `6000.4.8f1`에서도 기존 전체 플레이 흐름이 정상적으로 작동했다.

## 4. WebGL 전체 플레이테스트

- [x] `Start Wave` 버튼이 정상 작동한다.
- [x] 배속이 `1x → 2x → 3x → 1x` 순서로 순환한다.
- [x] 키보드 이동과 Space 공격이 정상 작동한다.

- [x] 증강 선택 후 `Start Wave`로 다음 웨이드를 시작할 수 있다.

WebGL 결과물은 `Builds/WebGL`에 생성했으며 `index.html`을 직접 실행하지 않고 로컬 HTTP 서버를 통해 테스트했다.

### 판정

WebGL의 전체 플레이 흐름과 입력은 정상이다.

## 5. UI 및 월드 배치 수정

### 우측 조작 UI와 코어

- 마지막 경로와 코어를 버튼 영역 아래로 이동했다.
- 입력 차단 패널의 검은 배경을 완전히 투명하게 변경했다.
- 투명 상태에서도 버튼 사이의 타워 미리보기와 실제 배치 차단이 유지됐다.
- 세 버튼과 입력 차단 영역을 위로 이동했다.
- 버튼 확대 상태와 코어의 최대 호흡 애니메이션 상태에서도 `Speed 1x`와 코어가 겹치지 않았다.

청록색 코어의 반복적인 크기 변화는 `CoreViewAnimator`의 기존 호흡 효과이며, 기본 크기를 기준으로 약 ±3% 변화한다.

### 좌측 상태 UI와 적 경로

- 일반 창에서 `Wave 1/5`와 첫 번째 경로가 겹치는 문제를 확인했다.
- 경로 전체를 상태 UI 아래쪽으로 재배치했다.
- 1차 재배치에서 경로 길이가 `19.3 → 18.3`으로 짧아져 초반 적의 진입 깊이가 증가했다.
- 아래 구간을 추가로 내려 전체 길이를 다시 `19.3`으로 복원했다.
- 수정 후 Wave 1~2 체감 밸런스가 이전과 비슷해졌다.

### 증강 패널 제목

- `CHOOSE AN AUGMENT` 제목 좌표가 왼쪽으로 밀려 `AN AUGMENT` 일부만 패널 밖에 표시되는 문제를 확인했다.
- 제목을 증강 패널 상단 중앙으로 이동했다.
- 수정 후 제목 전체가 표시되고 증강 카드와 겹치지 않았다.

### 증강 선택 결과

- 노란색 증강 선택 결과가 게임 제목과 우측 버튼에 겹치는 문제를 확인했다.
- 결과 UI를 아래로 이동하고 글자 크기와 표시 폭을 조정했다.
- 수정 후 증강 이름, 효과와 스택을 모두 읽을 수 있고 다른 UI와 겹치지 않았다.

## 6. 빌드 과정에서 확인된 문제

- 자동 배치 빌드 과정에서 Unity Licensing Client가 비정상 종료됐다.
- 이후 Unity Package Manager IPC 연결 실패도 반복됐다.
- 게임 코드와 WebGL 설정 오류는 아니었으며, Unity Editor의 `Build → Augmented Defense WebGL` 메뉴를 사용한 수동 빌드는 성공했다.
- 최신 빌드가 이전 화면으로 보이는 문제는 브라우저 캐시 때문이었고, 로컬 서버에 캐시 방지 헤더를 적용해 해결했다.
