# 2026-08-22 최종 기능 동결 플레이테스트 보고서

## 1. 테스트 목적

- 제출 후보 버전의 작은 사용성 개선을 검증한다.
- 게임 시작부터 증강 선택, 5웨이브 보스, 승리와 패배까지 전체 플레이 흐름을 재검증한다.
- `Play Again`과 `Restart`가 게임 상태를 완전히 초기화하는지 확인한다.
- 일반 창과 전체 화면에서 UI와 게임 화면이 안정적으로 표시되는지 확인한다.
- 테스트 통과 후 신규 기능을 동결하고 WebGL 제출 후보 빌드 단계로 전환한다.

## 3. 증강 카드 상호작용 테스트

- 세 증강 카드에 각각 마우스를 올리면 확대·강조 효과가 나타났다.
- 카드 사이 빈 공간에서는 Hover 효과가 나타나지 않았다.
- 카드를 누르면 눌림 강조가 표시됐다.
- 짧은 선택 지연은 플레이 흐름을 방해하지 않았다.
- 선택한 증강이 정상 적용됐다.
- 다음 증강 패널에서도 카드 상태가 초기화되고 정상 선택할 수 있었다.
- `CHOOSE AN AUGMENT` 제목이 정확히 표시됐다.

## 4. 적 체력바 가독성 테스트

- 피해받은 일반 적, 러너와 탱커의 체력바가 이전보다 명확하게 보였다.
- 세 적 유형의 체력바 크기가 동일하게 유지됐다.
- 러너의 작은 이미지 배율에도 체력바가 축소되지 않았다.
- 기본 Game 화면 배율에서도 검은 테두리를 구분할 수 있었다.
- 체력이 높을 때 초록색, 중간일 때 노란색, 낮을 때 빨간색으로 변화했다.
- 적의 이동, 회전과 피격 확대 중에도 체력바 크기와 수평이 유지됐다.
- 적이 사망하면 체력바가 정상적으로 사라졌다.
- 체력바는 기존 의도대로 적이 피해를 받은 뒤부터 표시됐다.

## 5. 타워 설치 결과 피드백 테스트

- 정상 구역에 타워를 설치하면 초록색 원이 퍼지며 사라졌다.
- 적 경로, 코어, 기존 타워, 디펜더와 전장 외곽에 설치를 시도하면 빨간색 원이 표시됐다.
- 골드가 부족한 상태에서도 빨간색 실패 효과가 표시됐다.
- 초록색과 빨간색 효과가 전장 배경 위에서 쉽게 구분됐다.
- 효과가 타워나 UI를 지나치게 가리지 않았다.
- 1배속과 3배속에서 효과 지속 시간이 동일했다.
- 연속 설치와 연속 실패 상황에서도 배치 판정이 정상 작동했다.

## 6. 게임 시작 목표 안내 테스트

- 게임 시작 시 화면 하단 중앙에 `DEFEND THE CORE · SURVIVE 5 WAVES`가 온전히 표시됐다.
- 목표 문구는 하단 조작 안내 및 다른 UI와 겹치지 않았다.
- 약 4.5초 동안 유지된 뒤 1.5초 동안 자연스럽게 사라졌다.
- 배속을 변경해도 표시 시간이 달라지지 않았다.
- 목표 문구가 표시된 위치에서도 정상적으로 타워를 설치할 수 있었다.
- `Restart`와 `Play Again` 후 목표 문구가 다시 표시됐다.
- 일반 창과 전체 화면에서 같은 위치를 유지했다.

## 7. 최종 회귀 테스트 — 시작 및 1~2웨이브

- 배경, 코어, 디펜더, 시작 타워와 황금색 적 이동 경로가 정상 표시됐다.
- 시작 상태는 골드 `70`, 코어 `100/100`, 웨이브 `1/5`, 속도 `1x`였다.
- 디펜더는 화면 밖으로 나가지 않았으며 이동과 공격이 정상 작동했다.
- 적 경로, 코어, 디펜더, 기존 타워, UI와 전장 외곽에는 타워를 설치할 수 없었다.
- UI 영역에서는 타워 미리보기 자체가 나타나지 않았다.
- 정상 구역에는 초록색 미리보기와 함께 타워를 설치할 수 있었다.
- `Start Wave`로 1웨이브를 정상 시작했다.
- 일반 적의 이미지, 이동 방향 회전, 피격 확대와 회전·축소·페이드 사망 효과가 정상 작동했다.
- 웨이브 종료 후 증강 패널, 제목과 카드 3개가 정상 표시됐다.
- 증강 선택 후 효과가 적용되고 2웨이브를 시작할 수 있었다.
- 러너는 일반 적보다 작고 빠르게 등장했으며 회전, 체력바와 사망 효과가 정상 작동했다.
- 속도는 `1x → 2x → 3x → 1x` 순서로 정상 순환했다.

## 8. 최종 회귀 테스트 — 3~5웨이브와 승리

- 3웨이브에는 일반 적과 러너가 등장했다.
- 탱커는 현재 웨이브 구성에 따라 4웨이브 초반부터 등장했다.
- 탱커는 일반 적보다 크고 느렸으며 체력이 높았다.
- 여러 적과 타워가 겹치는 상황에서도 공격, 피격과 사망 효과가 정상 작동했다.
- 3·4웨이브 종료 후 증강 패널과 다음 웨이브 진행이 정상 작동했다.
- 증강 선택 결과가 좌측 상태 UI 또는 우측 버튼과 겹치지 않았다.
- 5웨이브에서 보스 경고가 화면 중앙에 온전히 표시됐다.
- 보스 체력바와 등장 경고가 서로 겹치지 않았다.
- 보스는 탱커보다 확실히 컸으며 이동 방향대로 회전했다.
- 보스 체력은 `1000/1000`에서 타워와 디펜더의 공격에 따라 정상 감소했다.
- 보스 처치 시 회전·축소·페이드 후 승리 화면이 표시됐다.
- 승리 상태에서 속도 표시가 `--`로 변경됐다.

## 9. 초기화 및 패배 테스트

- 승리 화면의 `Play Again`을 누르면 골드 `70`, 코어 `100/100`, 웨이브 `1/5`, 속도 `1x`로 초기화됐다.
- 추가 설치한 타워가 사라지고 시작 타워만 남았다.
- 이전에 선택한 증강과 적용 효과가 모두 초기화됐다.
- `Start Wave`와 배속 버튼이 다시 정상 작동했다.
- 타워를 추가 설치하지 않고 디펜더 공격을 하지 않은 상태로 패배 흐름을 확인했다.
- 적이 코어에 도달하면 체력이 감소하고 흔들림과 붉은 갈색 점멸 피격 효과가 나타났다.
- 코어 체력이 0이 되면 `GAME OVER` 화면이 표시됐다.
- 패배 후 웨이브 진행과 타워 설치가 차단됐다.
- 패배 상태에서 속도 표시가 `--`로 변경됐다.
- `Restart` 후 모든 게임 상태가 다시 초기화됐다.

## 10. 발견한 문제와 조치

### 시작 목표 문구 위치

- 최초 구현에서 목표 문구가 상단 제목 영역과 겹쳤다.
- 하단 중앙으로 옮긴 뒤 Unity가 이전 컴파일 결과를 표시해 문구가 사라진 것처럼 보이는 상황이 있었다.
- `LowerCenter` 앵커와 피벗 처리를 명시적으로 추가하고 Unity 재컴파일 후 재검증했다.
- 최종적으로 일반 창과 전체 화면에서 하단 중앙 위치 및 페이드 효과가 정상 작동했다.

### 회귀 테스트 적 등장 순서 정정

- 최초 체크리스트에는 탱커가 3웨이브에 등장한다고 적었으나 실제 구성은 3웨이브에 일반 적과 러너, 4웨이브부터 탱커가 등장한다.
- 실제 웨이브 구성을 기준으로 정상 동작임을 확인했다.
