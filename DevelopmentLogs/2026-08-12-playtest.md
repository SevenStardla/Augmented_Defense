# 2026-08-12 플레이테스트 보고서

## 1. 테스트 목적

- 디펜더 공격속도와 사거리 증강이 후보에 등장하고 실제 능력치에 적용되는지 확인한다.
- 마지막 웨이브의 보스 등장, 경고 UI, 코어 피해 및 승리 처리가 정상인지 확인한다.
- 현재 프로젝트가 WebGL 대상으로 정상 빌드되는지 확인한다.

## 2. 테스트 환경

- 테스트 날짜: 2026-08-12
- 플레이테스트 Unity 버전: `6000.0.78f1`
- WebGL 빌드 Unity 버전: `6000.4.8f1`
- 실행 환경: Unity Editor PlayMode 및 BatchMode WebGL Build
- 테스트 씬: `Assets/Scenes/Main.unity`

## 3. 신규 디펜더 증강 테스트

### 디펜더 공격속도 증가

- [x] 증강 후보에 디펜더 공격속도 `+20%`가 등장한다.
- [x] 증강 선택 후 디펜더의 공격속도가 빨라진다.
- [x] 선택한 증강의 이름, 효과 및 스택이 화면 상단 중앙에 표시된다.

초기 확인 과정에서 증가량을 25%로 잘못 기록했으나, UI와 실제 설정을 다시 확인한 결과 **20%가 정확한 수치**임을 확인했다.

### 디펜더 사거리 증가

- [x] 증강 후보에 디펜더 사거리 `+25%`가 등장한다.
- [x] 선택 후 이전보다 먼 위치의 적을 공격하는 것이 체감된다.
- [x] 선택한 증강의 이름, 효과 및 스택이 화면 상단 중앙에 표시된다.

### 판정

신규 디펜더 증강 2종의 후보 등장, 능력치 적용 및 선택 결과 표시가 정상적으로 작동했다.

## 4. 마지막 웨이브 보스 테스트

### 등장 및 연출

- [x] 마지막 웨이브에 일반 탱커보다 큰 분홍색 보스가 등장한다.
- [x] 보스 등장 시 첫 줄에 `WARNING`, 다음 줄에 `OVERSEER BOSS INBOUND`가 표시된다.

### 전투 결과

- [x] 보스의 체력은 일반 탱커보다 높다.
- [x] 보스가 코어에 도달하면 코어 체력이 40 감소한다.
- [x] 보스 처치 후 승리 화면이 정상적으로 표시된다.
- [x] 승리 화면에 시스템 방어 성공을 나타내는 문구가 정상 표시된다.

### 밸런스 체감

- 공격 증강을 계속 선택한 경우 보스는 대체로 이동 경로 중간 지점 이내에서 처치됐다.
- 증강을 잘 선택하면 보스가 코어 근처까지 도달하지 못했다.
- 3배속 기준으로 전투가 지나치게 오래 걸리지는 않았다.

### 판정

보스의 등장, 경고 연출, 코어 피해와 승리 처리는 정상이다. 다만 공격 증강 조합에서는 보스가 코어에 위협을 주기 전에 처치되므로 추후 전체 밸런스 테스트에서 난이도를 다시 판단할 필요가 있다.
